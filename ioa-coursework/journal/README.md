# Journal

Append-only build log for the Internet of AI Agents coursework.

## Protocol

- **One entry per session, minimum.** Every session that modifies coursework content adds at least one journal entry before pushing.
- **Failures get the same care as successes.** Document what broke, what surprised you, and what you decided not to do, alongside what worked.
- **File naming:** `YYYY-MM-DD-slug.md` (e.g., `2026-11-07-phase-0-scaffold-rebuild.md`).
- **Append-only.** Do not edit past entries. If a past decision was wrong, document the correction in a new entry.

## Entry Template

```markdown
# YYYY-MM-DD — Title

## Context
What prompted this session.

## Built
What was created or changed.

## Broke / Surprised
What went wrong or was unexpected.

## Decisions
Choices made and their rationale.

## Open
Unresolved questions carried forward.

## Next
What the next session should pick up.
```
