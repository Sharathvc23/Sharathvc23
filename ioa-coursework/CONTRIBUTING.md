# Contributing

This coursework has a fixed scope: **8 modules**, covering the infrastructure layer for decentralized AI agent networks within the Project NANDA ecosystem.

## What belongs here

- Bug fixes (broken links, examples that don't run, incorrect claims)
- Clarifications to existing module content
- Additional exercises or worked examples within existing modules
- Glossary term additions or corrections
- Journal entries documenting build sessions

## What does not belong here

- **New modules.** The 8-module structure is deliberate. If you have an idea that doesn't fit an existing module, add it to Module 07's research map as an open problem.
- Content that requires non-public sources
- Examples with dependencies beyond stdlib + requests (unless declared in the module)

## Before submitting

1. Run `python scripts/check_links.py` — must exit 0
2. Run `bash scripts/run_examples.sh` — must exit 0
3. Add a journal entry if you modified module content

See [CLAUDE.md](CLAUDE.md) for voice, rules, and the module acceptance checklist.
